# Markdown fixtures

`koi8r_report.md` (Russian, KOI8-R) and `gbk_weekly.md` (Chinese, GBK)
are docling.rs's own samples for the statistical charset detection of
#675: no byte-order mark, not UTF-8, read as their own letters.

`display_math.md` is docling.rs's own: `$$…$$` paragraphs that become
formula items, next to inline math, prices and a linked formula that stay
text. The rest are docling.rs regression cases or mirrored from the corpus
(`mirror.txt`).
